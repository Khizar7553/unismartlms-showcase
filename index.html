🤖 AI-Assisted Features

📚 1. Smart Library AI — Document Retrieval

  • Processes supported uploaded documents for document-based question answering.
  • Divides document text into smaller chunks for retrieval.
  • Uses custom 384-dimensional character-trigram vectors and cosine similarity to compare text representations.
  • Retrieves relevant document content to support the question-answering workflow.

The current vector-generation implementation uses character-trigram hashing rather than a pretrained semantic embedding model.

🎤 2. Voice Assistant

  • Supports speech input through browser speech-recognition functionality where available.
  • Converts recognized speech into text for processing.
  • Uses browser text-to-speech functionality for spoken output.
  • Supports voice-driven interaction and navigation for implemented commands.

📊 3. Research Assistant

  • Provides an experimental interface for academic research assistance.
  • Explores document analysis and research-related tasks.
  • Offers a foundation for future improvements in research-paper processing and assistance.

This component is experimental and may require further development for improved reliability and accuracy.

📚 Library Management Features

  • Book and library record management.
  • Borrowing request workflows.
  • Separate interfaces for administrators, librarians, and students.
  • User management and role assignment.
  • Authentication using ASP.NET Core Identity.
  • Document upload and retrieval functionality.
